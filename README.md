# DAMSA_OfflineSoftware
  
usage:  
  
$ git clone <git address>  
$ make -j<your available cpu threads>  
$ For plotter mode to view individual waveform plots: ./dmssoft -p /path/to/file.txt
$ For batch mode to generate ROOT file for analysis: ./dmssoft -b /path/to/input.txt /path/to/output.root
